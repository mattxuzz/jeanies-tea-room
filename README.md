## 二、最快部署：GitHub Pages

1. 注册/登录 github.com（免费账号即可）。
2. New repository → 名称如 `my-tea-room` → 选 **Public** → Create。
3. 进入仓库 → Add file → Upload files → 把 `01_珍珠的茶室_含数据_直接上传/` 里的**全部文件**（`index.html` + `manifest.webmanifest` + 3 个 png）拖进去 → Commit changes。
4. Settings → Pages → Source 选 **Deploy from a branch** → Branch 选 **main** → 目录选 **/ (root)** → Save。
5. 约 1 分钟后访问：`https://<你的用户名>.github.io/<仓库名>/`

其它云（腾讯云 CloudBase 静态托管、Vercel、Netlify、EdgeOne Pages、任意 Nginx/对象存储）同理：把 `01` 文件夹内容传到站点根目录，入口为 `index.html`。

> 本地双击 `index.html` 也能直接用，但浏览器对 `file://` 的 localStorage/清单支持有限，正式使用请走 http(s) 托管。

## 三、数据机制（重要，务必看懂）

- 数据存在**每台设备各自的浏览器 localStorage 里**，不存在云端服务器上。云端只是"分发这个网页"。
- `01` 的 `index.html` 内嵌了一份数据备份，**仅在该设备第一次打开（或清空过浏览器数据）时**写入；之后以本机数据为准，你在网页里的增删改刷新后不会丢。
- 想强制回到这份备份快照：访问 `https://<你的域名>/?reset`。
- **换设备 / 换浏览器不会自动同步**。跨设备请用 App 内「备份与同步 → 导出数据(JSON)」导出，再到另一台设备导入。
- 建议部署成功后立刻导出一份 JSON 文件存本地，以后再也不依赖任何平台。

### 隐私提醒
`01` 是**含数据版**，你的茶单、购买价格、冲泡笔记会写进公开的 HTML 文件里，任何拿到链接或仓库的人都能看到。如果不希望公开，请改用 `03_源码与数据备份/珍珠的茶室.html`（干净源码）作为 `index.html` 上传，部署后再用自己的 `珍珠的茶室-数据备份.json` 导入。

## 四、添加到手机桌面（PWA）

已配好 `manifest.webmanifest` + 图标 + iOS meta，部署到 **https** 后：
- iPhone Safari：分享 → 添加到主屏幕
- Android Chrome：菜单 → 添加到主屏幕 / 安装应用

会以全屏独立窗口打开，像原生 App 一样。

**注意：刻意没有加 Service Worker。** 源码里的注释写明：微信 WebView 的 SW 缓存会锁死旧页面、导致无法更新，因此启动时会主动注销已有的 SW。这意味着"添加到桌面"可用，但**不承诺离线打开**，需要联网。请不要自行补 SW，否则可能重新引入缓存锁死问题。

## 六、历史背景（为什么有这些文件）

原托管在 CloudStudio 的链接被平台回收，网关返回 403、沙箱返回 404，数据因只存在浏览器里而一度无法访问。后通过 DevTools 提取 localStorage 抢救出数据（原始导出有双重转义，已修正），才有了含数据版与恢复工具。为避免再次发生：**请务必保留 `03` 里的 JSON 备份文件**。
